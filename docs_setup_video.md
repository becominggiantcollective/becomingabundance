# Setup Video Tutorial

A 5-minute guide to setting up the Polygon Flashloan Arbitrage Bot.

**Steps**:
1. Install Python 3.8+ and Node.js.
2. Clone the repo: `git clone https://github.com/your-username/polygon-arbitrage-bot.git`.
3. Install dependencies: `pip install -r requirements.txt`, `npm install --save-dev hardhat --unsafe-perm`.
4. Create a Telegram bot with @BotFather for `TELEGRAM_TOKEN`.
5. Set up `.env` with wallet keys and tokens.
6. Deploy: `python deploy.py --mainnet`.
7. Run: `python arb_monitor.py`.
8. Control via Telegram: `@YourBotName /start`.
